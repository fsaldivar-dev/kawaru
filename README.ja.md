## 「聞こえてますか？」は卒業。ちゃんと伝わる自己紹介を

ビデオ通話では、誰もが小さな文字の名前がついた小さな枠のひとつ。Kawaruは、テレビ番組が司会者に出すものを
あなたの映像にも出します。名前と役職、今日のテーマ、SNSのアカウント、
席を立つときの「5分で戻ります」まで。

しかも、出すのは手で合図したその瞬間。カメラが手を読み取るので、あなたは話し続けるだけです。

## スタジオ品質のテロップ

<p align="center">
  <img src="docs/img/rotulos.jpg" alt="Kawaruのテロップとテーマ：ミニマル、ビジネス、ネオン、ウッド、カスタム、そして全画面カード">
</p>

- **5つの種類：** 名前を出すローワーサード、テーマを出すバナー、バッジ（「ライブ」「録画中」）、
  全画面カード（「まもなく開始」）、そしてロゴ付きのSNSアカウント。
- **5つのテーマ：** すぐに使えるミニマル、ビジネス、ネオン、ウッド。カスタムなら
  色もフォントも形も自由に選べます。あなたのブランドを、あなたのスタイルで。
- **同時に何枚でも、重ならずに：** 名前、LinkedIn、今日のテーマを一緒に出しても、自動で並びます。
- **置き場所は自由：** プレビューの上でテロップをドラッグすれば、そこに固定されます。
- **登場にも演出を：** スライド、フェード、バウンス、ワイプ。消すまで出しておくことも、自動で消すこともできます。

## 会議を眠くさせないエフェクト

<p align="center">
  <img src="docs/img/efectos.jpg" alt="Kawaruのエフェクト：分身、離席の看板、質問の吹き出し、紙吹雪、休憩、スポットライト">
</p>

| エフェクト | こんなときに |
|---|---|
| **紙吹雪** | チームの成果をその場でお祝い。絵文字を探す必要はありません。 |
| **質問の吹き出し** | 話している人をさえぎらずに、発言したいと伝えられます。 |
| **離席の看板** | 席を立っても「回線が落ちた？」と心配されません。 |
| **休憩** | 画面にカウントダウン。いつ再開するか全員に伝わります。 |
| **スポットライト** | あなたはカラー、背景はグレーに。注目してほしいときに。 |
| **分身** と **変わり身** | 会議がいつも真面目である必要はありませんから。 |

看板、吹き出し、紙吹雪の文字はあなた次第。好きな言葉を入れてください。

## 私たちのではなく、あなたのジェスチャを

Kawaruにはすぐ使える手のポーズ（サムズアップ、開いた手のひら、2本指など）が用意されていますが、おすすめは
**自分のポーズを記録する**こと。好きな形で手を出し、3回繰り返してあなたのクセを覚えさせれば、
その合図はあなただけのもの。思い出せるように写真も保存されます。

手がふさがっているときは？ エフェクトにもテロップにも、それぞれ**キーボードショートカット**があり、
通話アプリが最前面にあっても使えます。**メニューバーのアイコン**にもボタンがあります。

## macOSのために作られたアプリ

<p align="center">
  <img src="docs/img/app-rotulos.jpg" width="49%" alt="Kawaruの「テロップ」セクション。ギャラリーとエディタ">

- **相手に見える映像を、先に確認。** エフェクトもテロップも、使う前に通話に映るとおりの姿で確認できます。
- **使い方はアプリが教えてくれます。** ようこそチュートリアルと、ウインドウを順に案内するツアー付き。
- **邪魔になりません。** メニューバーに常駐。ウインドウを閉じても、次の通話に備えて待機しています。
- **カメラを大切に扱います。** カメラをオンにするのは通話で使われているときだけ。それ以外はオフのままです。

## あなたの映像は、Macの外に出ません

Kawaruにはサーバも、アカウントも、アクセス解析もありません。カメラ映像はAppleの技術を使ってあなたのMac上で
処理され、外に出るのはあなたが通話に送る映像だけ。ディスクに保存されるのは、記録したジェスチャの写真と
選んだアイコンだけで、どちらもあなたのユーザフォルダ内に置かれます。

## 3ステップで始めよう

1. **[Kawaruをダウンロード](https://github.com/fsaldivar-dev/kawaru/releases/latest/download/Kawaru-0.2.0.dmg)**して
   ファイルを開き、「アプリケーション」にドラッグします。
2. **アプリを開いて、チュートリアルに沿って進めます。** カメラを許可し、仮想カメラをインストールして、最初のジェスチャを試します。
3. **ビデオ通話アプリで、カメラに「Kawaru」を選びます。** これで準備完了です。

[使い方ガイド](docs/guia.ja.md)では、よくあるトラブルの解決方法も含めて、すべてを詳しく説明しています。

## 現在の状況

現在のバージョンは **0.2.0** です。Appleによる署名と公証を受けています。アプリはスペイン語、英語、ポルトガル語、フランス語、日本語、簡体字中国語、韓国語に対応し、Macの言語設定に合わせて表示されます（このページのスクリーンショットはスペイン語版のものです）。動作確認は
macOS 26を搭載したMacで行っています。うまく動かない場合は、[Issueを作成](https://github.com/fsaldivar-dev/kawaru/issues)して、
お使いのMacの機種とmacOSのバージョンをお知らせください。

## 開発者の方へ

Kawaruは外部依存のないSwiftパッケージです。手の読み取りと人物の切り抜きにVision、合成にCore Image、
システムにカメラとして認識させるためにCoreMediaIOのカメラ機能拡張を使っています。

```bash
scripts/provision.sh        # una vez: obtiene de Xcode el perfil para la cámara virtual
scripts/build.sh --install  # compila e instala en /Applications
```

（1行目は最初に一度だけ実行し、仮想カメラ用のプロファイルをXcodeから取得します。2行目はビルドして /Applications にインストールします。）

開発者アカウントを設定したXcodeと `xcodegen`（`brew install xcodegen`）が必要です。署名・公証済みの
バージョンを公開する手順は、[`scripts/release.sh`](scripts/release.sh) のコメントをご覧ください。
アプリのテキストはスペイン語で書かれており、翻訳は `assets/idiomas` にあります。`scripts/idiomas.sh` で
翻訳漏れがないかを確認できます。`scripts/previews.sh` は、`assets/modelo` の写真をアプリ本来の合成処理に通して、
ギャラリーの画像を再生成します。
