## 安装

1. 从[版本发布页面](https://github.com/fsaldivar-dev/kawaru/releases/latest)下载 `Kawaru-0.2.0.dmg`。
2. 打开它，把 **Kawaru** 拖到“**应用程序**”文件夹。它必须放在那里：macOS 只允许该文件夹中的 App 安装虚拟摄像头。
3. 从“应用程序”中打开 Kawaru。

需要 macOS 14 或更高版本。Kawaru 会跟随你 Mac 的语言：西班牙语、英语、葡萄牙语、法语、日语、简体中文或韩语。

## 欢迎教程

![欢迎教程](img/app-tutorial.jpg)

第一次打开时，Kawaru 会用五步带你上手：

1. **它是什么。** 快速了解它能做什么。
2. **你的摄像头。** 点按“允许使用摄像头”，并在 macOS 的提示中同意。
3. **虚拟摄像头。** 点按“安装虚拟摄像头”。macOS 会请你批准：打开“系统设置”>“通用”>“登录项与扩展”>“相机扩展”，然后打开 Kawaru。
4. **你的第一个手势。** 在摄像头前竖起大拇指，保持半秒。你会看到 Kawaru 在你手上识别的点，以及三个标记，每识别一次就填满一个。
5. **就绪。** 如何在通话中使用的小结。

教程结束后，**窗口导览**会逐一指给你看窗口的每个部分，并告诉你它的用途。

![窗口导览](img/app-recorrido.jpg)

这两者随时都可以从“**帮助**”菜单中重新查看。

## 在通话中使用

在 Meet、Zoom、Teams 或任何视频 App 中，打开摄像头设置，选择 **Kawaru**。从这一刻起，别人看到的就是加上了你所开启内容的画面。

不需要一直开着 Kawaru 的窗口：只要 App 还在菜单栏里就行。

> Meet 和 Zoom 给你自己看的是镜像画面，所以你看到的字幕条是反的，别人看到的则是正的。如果觉得别扭，可以在通话 App 的设置中关闭“镜像我的视频”。

## 特效

![“特效”部分](img/app-efectos.jpg)

“**特效**”部分里，每个特效都有一张卡片。选中一张后，右侧会显示真实特效的视频，以及你可以调整的内容：

- **实时试用：** 在“直播”部分把它叠加到你的摄像头画面上。
- **手型：** 触发它的手势。选“无”则只能用快捷键触发。
- **自定手型：** 录制你自己的手势（参见[手势](#手势)）。
- **文字或时长**（部分特效提供）：告示牌的两行字、气泡的两行字、撒花时的那句话，以及休息的分钟数。

开启特效的手势，同样可以把它关闭。“撒花”和“休息”结束后会自动消失。

| 特效 | 效果 |
|---|---|
| 替身 | 你在一团烟雾中消失，只留下一截木桩。需要先[拍摄背景](#拍摄背景)。 |
| 分身 | 你的分身出现在两侧。 |
| 离开告示牌 | 用一块写着你的文字的告示牌遮住画面。 |
| 提问气泡 | 在你旁边显示一个对话气泡。 |
| 撒花 | 彩纸纷飞，外加一句话。 |
| 休息 | 全屏倒计时。 |
| 聚光灯 | 你是彩色的，背景变灰。 |

## 字幕条

![“字幕条”部分](img/app-rotulos.jpg)

字幕条是叠加在你画面上的文字。和特效不同，你可以**同时显示多个**。

### 创建字幕条

点按**新建字幕条**，然后选择类型：

- **人名条：** 你的姓名和职位。
- **横幅：** 一行标题，在顶部或底部。
- **角标：** 角落里的一个小标签。
- **全屏卡片：** 铺满整个画面的信息。
- **社交账号：** 平台标志和你的用户名。

### 打造你的风格

在右侧的编辑器中：

- **文字：** 显示的内容。
- **主题：** 极简、商务、霓虹、木纹或**自定义**。选择“自定义”后，你可以设定背景色、文字颜色和强调色，从七种字体中任选其一，还能调整圆角的大小。
- **位置：** 选一个角落，或者**在预览画面上拖移**，放到任意位置。“还原”会把它送回角落。
- **大小。**
- **入场：** 滑入、淡入、弹跳或展开。“查看动画”可以播放一遍。
- **停留：** 直到你移除，或者 5 秒到 1 分钟。

对于社交账号字幕条，**选取图片…** 可以把平台标志换成你自己的图片。

### 同时显示多个

同在一个角落的字幕条会按你开启的顺序叠放，互不遮挡。你拖移摆放过的字幕条则留在原处。

### 显示与移除

可以用**播出**按钮、它的手势、它的快捷键，或者从菜单栏操作。

## 手势

把手势保持**半秒**多一点，它就会触发。想再用一次，得先**把手放下**：只要手还保持着同一个手型，就不会重复触发。

### 现成的手势

两指点额、敬礼、两指朝上、张开手掌、竖大拇指和双手结印。

### 录制你自己的手势

1. 在某个特效或字幕条中，点按“自定手型”旁边的**录制…**。
2. 你有三秒钟摆好手型。你会看到 Kawaru 识别的点：如果没有出现，说明它没看到你的手。
3. 录制时保持不动。
4. **重复三次**，每次之间把手放下。不必做得一模一样：这几次重复正是为了让它学会你实际的做法。

Kawaru 会保存一张你做这个手势的照片，帮你记住它。

### 让手势更容易识别的小技巧

- 每个手势都要和其他手势**明显不同**。如果有两个太像，Kawaru 会提醒你。
- 单手比双手更容易识别。如果用双手，**不要让它们碰在一起**：贴在一起时看起来像一只手。
- 正面光线要充足，手要在画面之内。
- **练习手势**让你可以放心尝试，不会触发任何东西。

## 键盘快捷键

即使通话 App 在最前面，它们也能用。

| 快捷键 | 触发内容 |
|---|---|
| ⌃⌥1 … ⌃⌥7 | 各个特效，按图库中的顺序 |
| ⌃⌥⇧1 … ⌃⌥⇧9 | 你的字幕条，按列表中的顺序 |

## 菜单栏与后台运行

Kawaru 会在菜单栏中放一个图标。在那里你可以：

- 点一下即可开启或关闭任意特效或字幕条。
- 暂停**手势**（快捷键和按钮照常可用）。
- 打开**登录时打开**。
- 打开窗口，或者退出。

关闭窗口并不会退出 App。窗口关闭时，只有当通话正在使用“Kawaru”摄像头，你的摄像头才会开启。

## 拍摄背景

把你从画面中移除的特效，需要知道你身后有什么。在**摄像头**中点按**拍摄背景**，然后离开画面：三秒后它会拍下一张空背景的照片。照片仅保存在内存中。移动摄像头后请重拍。

## 遇到问题时

**通话 App 里找不到“Kawaru”摄像头。**
请在“摄像头”部分确认显示的是“虚拟摄像头已启用”。如果安装时通话 App 已经开着，请把它关掉再重新打开。在 Chrome 中，有时需要把整个浏览器退出。

**通话 App 显示一张卡片，写着“Abre la app Kawaru”（请打开 Kawaru App）。**
Kawaru 没有在运行。打开它即可；它可以只待在菜单栏里。

**某个手势识别不出来。**
用“练习手势”看看手上的识别点。如果没有出现，说明光线不足或手在画面之外。如果点出现了却不计数，请重新录制。

**某个手势触发了别的东西。**
你有两个手势太像了。请换一个录制。

**Meet 或 Chrome 给我加了一个我没选的背景。**
那个背景是浏览器加的，不是 Kawaru。请检查 Chrome 自身以及 macOS 的视频效果（菜单栏中的绿色摄像头图标）。

**Kawaru 的图标显示成灰色。**
这是 macOS 的图标风格（“系统设置”>“外观”），会影响所有 App。

## 隐私

- 摄像头画面在你的 Mac 上处理。Kawaru 不会把它发送到任何地方。
- 没有账号，也没有数据统计。
- 你录制手势时的照片和你为字幕条选取的图标保存在 `~/Library/Application Support/Kawaru` 中，随时可以删除。
